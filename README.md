## 🚀 Projetos em destaque

### 📸 QR Moments

**Uma solução criada para simplificar o compartilhamento de fotos em eventos.**

Em um cenário onde quase tudo exige um aplicativo, o QR Moments permite que os convidados acessem, enviem e compartilhem fotos diretamente pelo navegador, sem instalar nada ou criar uma conta.


**Stack:** Next.js · TypeScript · Firebase · Firestore · Storage · Stripe · Asaas · Resend

🌐 [qrmoments.com.br](https://qrmoments.com.br)
